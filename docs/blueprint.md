# **App Name**: TaskFlow

## Core Features:

- Employee Profile: Display a personalized employee profile section showing name, photo, role, and department.
- Task Overview: Present a task overview panel summarizing total, completed, pending, and priority tasks with color indicators.
- Interactive Task List: Enable interactive task list with checkboxes, task titles, deadlines, priority tags, and assigned-by information.
- Calendar View: Provide calendar view highlighting upcoming deadlines.
- AI Task Prioritization: Suggest a default priority tag for tasks by analyzing title and deadline using a tool that applies prompt engineering.
- Search and Filter Tasks: Enable search and filtering of tasks by priority, due date, and status.
- Theme Toggle: Add a Light/Dark mode toggle

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey a sense of professionalism and trustworthiness.
- Background color: Light gray (#F5F5F5), for a clean, unobtrusive backdrop in light mode.
- Accent color: Orange (#FF9800) to highlight important tasks and CTAs, contrasting well with the primary color.
- Body and headline font: 'Inter', a grotesque-style sans-serif for its modern, neutral look; suitable for headlines or body text
- Use consistent and clean icons from a minimalist set to represent task status, priority, and actions.
- Implement a responsive grid-based layout with rounded corners and subtle shadows for a modern, user-friendly interface.
- Incorporate subtle transitions and animations for interactive elements such as task completion and priority changes.
